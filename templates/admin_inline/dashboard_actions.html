Enrichissement YGOrganization (YGResources)

Lourd Écrit en DB

Ordre conseillé la première fois : sync index → init → backfill (répéter si besoin) → manifest. Ensuite, lancer sync Q&A ponctuellement.

  • Sync index EN : télécharge l’index des noms anglais (volumineux, rarement).
  • Init révision : enregistre la révision de référence.
  • Backfill : associe passcodes de cards aux IDs YGOrg.
  • Manifest : télécharge le JSON brut cartes (card_raw).
  • Sync Q&A : importe des Q&A récents pour les associations.
