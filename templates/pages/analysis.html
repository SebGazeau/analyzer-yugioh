Aperçu des probabilités (référence)

Trois valeurs pour le premier groupe du tableau « Probabilités exactes » (premier engine ou première catégorie par ordre alphabétique). Utile pour comparer vite main à 5, main à 6, et la taille de main choisie pour la simulation.

Si ce groupe couvre presque tout le Main Deck, les pourcentages se rapprochent de 100 %.

Répartition par catégorie

Largeur de chaque segment = part du Main Deck assignée à une catégorie dans le Builder. Survol d’un segment pour le détail.

En dessous : d’abord une simulation aléatoire (approximation), puis le tableau avec les probabilités exactes (loi hypergéométrique).

Simulation de tirage (aléatoire)

Mille tirages simulés par catégorie : utile pour visualiser une distribution, distincte des pourcentages exacts du tableau.

« Tirer une carte » ajoute une carte au hasard (sans remise) jusqu’à la taille de main choisie. « Run 1000 sims » remplit les histogrammes : le graphique principal suit la catégorie du menu ; les mini-graphiques comparent toutes les catégories.

« Run 1000 sims » nécessite au moins une carte dans le Main et au moins une carte avec une catégorie (via « Modifier la carte » dans le Builder).

Probabilités exactes (hypergéométrique)

Le tableau regroupe le Main Deck par engine, par catégorie (Starter, Extender, etc.) et par groupe de catégories. Les colonnes ≥1 à ≥6 donnent la probabilité d’avoir au moins 1, 2, … 6 cartes du groupe dans une main du même format (5 ou 6 cartes, selon les boutons de la simulation). Calcul : tirage sans remise (loi hypergéométrique). Clique sur un en-tête de bloc (Engines, …) pour replier.
